## 1. 개발 의도

학교에서 학생들이 자신의 꿈을 찾고 미래를 준비하는 과정이 중요하다고 생각했습니다. 하지만 아직 꿈을 정하지 못했거나 어떤 직업이 자신에게 맞는지 모르는 학생들도 많습니다.

이러한 학생들이 자신의 관심사를 발견하고 다양한 직업을 탐색하며, 작은 목표를 하나씩 실천하면서 꿈을 구체적으로 만들어 갈 수 있도록 DREAM LOG를 개발했습니다.

## 2. 적용 대상

- 사용 대상: 초등학생, 중학생, 고등학생 등 자신의 진로와 미래를 탐색하고 싶은 학생
- 사용 상황: 자신의 관심사와 적성을 알아보고, 다양한 직업을 탐색하거나 미래의 목표를 세우고 실천할 때

## 3. 주요 기능과 사용 방법

| 기능 | 설명 |
| --- | --- |
| DREAM BOARD | 나의 꿈과 목표를 등록하고 관리할 수 있습니다. |
| ONE STEP | 꿈을 이루기 위해 매일 실천할 작은 목표를 설정하고 기록합니다. |
| MY JOURNEY | 꿈을 향해 노력한 과정과 경험을 기록할 수 있습니다. |
| MY GROWTH | 활동과 실천 기록을 바탕으로 나의 성장을 확인합니다. |
| CAREER BOOK | 다양한 직업의 정보와 특징을 탐색할 수 있습니다. |
| DREAM LAB | 진로 퀴즈, 직업 월드컵 등 다양한 활동을 통해 직업을 재미있게 알아볼 수 있습니다. |

**사용 방법**

1. 앱 주소에 접속합니다.
2. 관심사와 꿈을 등록하거나 진로 탐색을 시작합니다.
3. 다양한 직업을 알아보고 나만의 목표와 실천 과제를 설정합니다.
4. 활동과 경험을 기록하고 나의 성장 과정을 확인합니다.

## 4. 기대 효과

학생들이 자신의 관심사와 적성을 발견하고 다양한 진로 가능성을 알아볼 수 있습니다. 또한 스스로 목표를 세우고 작은 행동을 꾸준히 실천하면서 자기 주도적인 진로 설계 능력과 성취감을 기를 수 있습니다.
